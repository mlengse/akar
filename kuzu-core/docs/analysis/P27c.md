# Vec Allocation Optimization Opportunities in kuzu-core

## Summary

I found **50+ significant optimization opportunities** across all five target directories. The most impactful are in the **hot query execution paths** (`join_ops.rs`, `aggregatehashtable.rs`, `scan.rs`, `recursiveextend.rs`, `filter.rs`), where `Vec::new()` is used in tight loops or known-size situations where `Vec::with_capacity()` would eliminate repeated reallocations.
