# Akar Full-Text Search Extension

Full-text search capabilities for the Akar database engine.

**Components:**
- `Stemmer` — English Porter stemmer
- `Tokenizer` — configurable tokenizer with stop word filtering
- `TfIdf` — TF-IDF scoring
- `Bm25` — BM25 ranking

**Functions:** `stemmer`, `tokenizer`, `tf_idf`, `bm25`, `query`, `stop_words`

**Tests:** 14
