# 5. Akar — Boundaries & Interfaces

> Every surface a user can touch: the query language, the public Rust API, the shells, the FFI ABI, the wire protocol, and the configuration surface.

## The query language (openCypher)

The primary boundary of the engine. Akar supports the openCypher surface — `MATCH`, `OPTIONAL MATCH`, `WHERE`, `WITH`, `RETURN`, `UNWIND`, `FOREACH`, `MERGE`, `CREATE`/`DELETE`/`SET`, subqueries, parameters (`$param`), and late-bound `LIMIT $n`/`SKIP $n` (`akar-parser/src/ast.rs:313,236-242`) — plus Akar-specific DDL and calls:

| Category | Statements / calls |
|---|---|
| Core | `CREATE NODE TABLE` / `CREATE REL TABLE` (with PKs), `DROP TABLE`, `CREATE INDEX`/`DROP INDEX`, `COPY FROM`/`COPY TO`, `EXPLAIN` (Logical/Physical/Profile) |
| FTS | `CREATE FTS INDEX ON :Label (col) [WITH TOKENIZER('...')]` (P109.1) |
| Vector | `CREATE VECTOR INDEX`; `CALL vector_similarity_scan(table, column, query_vector, k)` |
| Graph tools | `CALL page_rank(...)`, `louvain(...)`, `wcc(...)`, `scc(...)`, `scc_ko(...)`, `kcore(...)`, `shortest_path(...)`, `dijkstra(...)`, `aspd(...)`, `spreading_activation(...)`, `node2vec(...)` (ALGO extension) |
| Interop | `CALL duckdb_query(...)`, `sqlite_query(...)`, `sql_query(...)` (Postgres), `neo4j_migrate(...)`, `http_get(...)`, `create_embedding(...)`, `read_markdown_wiki(...)` |
| Statements shape | 33 `Statement` variants, 33 `BoundStatement` variants, 59 `LogicalOperator`s |

## The public Rust API (`akar-main`)

The single published crate surface (`cargo add akar-main`).

- `Database::new(path, config)` — opens/creates a database directory (default `:memory:`), loads built-in extensions.
- `Database::connect_tcp(addr)` — the TCP client for the (deprecated) `akar-server` (`database.rs:512`).
- `Connection::query(cypher)` / `query_with_params` — read path over the plan cache (`connection/query.rs:21`); `Connection::transaction()` — MVCC write path (`connection/transaction.rs:9`).
- `PreparedStatement` — reused plans with typed parameters.
- `QueryResult` — Arrow-backed rows (`has_next`/`get_next`/column names).

## The interactive shell — `akar-cli`

```
akar-cli [database_path] [--skip-wal] [--salvage]
```

| Surface | Behavior |
|---|---|
| Positional arg | Database path; default `:memory:` |
| Piped stdin | Interpreted as a script when not a TTY |
| Dot commands | `.exit`/`.quit`/`.help`/`.tables`/`.schema`/`.mode <table&#124;csv&#124;json&#124;line&#124;column&#124;box&#124;html&#124;latex>`/`.import <csv> <table>`/`.export <file> <query>` |
| Output modes | Default `Box`; eight renderers (`format_output`, `main.rs:490`) |
| History | Persisted to `<data_dir>/akar/history.txt`; confidential `CALL`s (S3/GCS/Azure) are skipped (`is_confidential_call`) |
| Exit codes | 2 on unknown arguments |

## The C FFI (`akar-c`)

A minimal, panic-safe `extern "C"` ABI. Handles are opaque `#[repr(C)]` structs; results are released with `akar_query_result_destroy` — never C `free()`.

| Function | Signature |
|---|---|
| Init | `int akar_database_init(const char* path, akar_system_config* config, akar_database* out)` |
| Connect | `int akar_connection_init(akar_database db, akar_connection* out)` |
| Query | `int akar_connection_query(akar_connection conn, const char* query, akar_query_result* out_result, char** error_message)` |
| Errors | `AkarSuccess = 0` / `AkarError = 1`; `akar_error_message_free(char*)` |
| Safety | Every entry point is wrapped in `catch_unwind` (the crate ships `panic = "abort"` in release) so a panic cannot cross the FFI boundary |

## The WASM binding (`akar-wasm`)

`wasm_bindgen` classes for Node/browser: `AkarDatabase::new(db_path)` accepts only `""`/`":memory:"` (in-memory enforced at the constructor), `AkarConnection::query/prepare/execute`, `QueryResult::has_next/get_next/get_column_names`. Cells convert through `serde_wasm_bindgen`; `console_error_panic_hook` is installed.

## The Python package (`akar`)

`pip install akar`; modeled as a **Kuzu drop-in**. The top-level API is the familiar `Database(path)`, `Connection(db)`, `Connection.query(cypher)` / `execute(cypher, params)`, and a Kuzu-shaped `QueryResult` (`has_next()`, `get_next()`, `get_all()`, `rows_as_dict(True)`, `__iter__`, `len(r)`, truthiness). Sub-modules expose the engine's advanced features: `knn`, `lstm`, `spread`, `louvain`, `search`, `dream`. Dialect translation (`translation.rs`) and side-parameter interpolation (`param_interp.rs`) make legacy Kuzu/kairos bootstrap SQL run unchanged, and `CALL QUERY_VECTOR_INDEX(...)` falls back to a brute-force Cypher rewrite.

## The TCP daemon — `akar-server` (deprecated for production, P124)

Retained as a wire reference / test harness. Client entry is `Database::connect_tcp(addr)` in `akar-main::remote`.

| Item | Contract |
|---|---|
| Protocol | Length-prefixed JSON (`WireRequest`/`WireResponse`, `remote.rs:46,88`) |
| Default port | 9876; `--addr` default 127.0.0.1 |
| Frame cap | 128 MiB both sides |
| Auth | `--auth-token <32-byte hex>`; empty disables |
| Ops | `query`, `ping`, `flush` (CHECKPOINT), `stats`, `export` (EXPORT DATABASE), `shutdown`, `dream_control` (run/resume/pause/status) |
| Flags | `--db`, `--port`, `--idle <secs>`, `--json-sidecar <path>`, `--read-only`, `--skip-wal` (salvage redo, P114.2), `--checkpoint-threshold <bytes>` (16 MiB default) |
| Sidecar | JSON `protocol: "json-v1"` (host/port/token/pid/db_path/started_at) |

## Extension contract (the plugin boundary)

`Extension: Send + Sync` with `fn name(&self) -> &'static str` and `fn load(&self, context: &ExtensionContext) -> Result<(), String>` (`akar-extension/src/lib.rs:20-27`). The context hands plugins three registration handles — `register_scalar_function`, `register_aggregate_function`, `register_table_function` (`context.rs`) — plus the Catalog and VFS. Table functions wanting graph access implement the GDS variant `TableFunction::CustomTableWithGraph` (`P52.46`), receiving `Option<&dyn GraphDataSource>` with live edges from `CatalogGraphSource`.

## Storage-format boundaries

- **On disk:** DB directory holds data files per table + `catalog.json` (`CATALOG_FILE_NAME`, `akar-main/src/database.rs:23`) + WAL + checkpoint milestones.
- **Readers:** a compiled-in `COPY FROM` stack for CSV/Parquet/JSON/NPY feeds the store.
- **Compatibility:** on-disk format is versioned (`STORAGE_VERSION`); opening a newer format yields an explicit error, never silent corruption.
